# ПроБьюти — сайт студии красоты

Полноценный веб-сайт студии красоты **ПроБьюти** (Волгоград, ул. Никитина, 127А) — без зависимостей от Telegram.

**Разделы:** Услуги (25 услуг с ценами) · Галерея работ (по категориям) · Отзывы (все отзывы Dikidi + живое обновление) · Контакты + онлайн-запись на Dikidi · Кабинет администратора.

## Дизайн (2026)

Тёмная тема «ночная вишня» + премиальный glassmorphism — современный, а не «2010-й»:

- **Aurora-фон**: тёмная база `#17100E` + плавно дрейфующие цветные орбы (orb-анимации) + кинематографичное зерно поверх.
- **Стеклянные панели** (`backdrop-filter: blur + saturate`), стеклянная навигация, появляющаяся при скролле.
- **Bento-сетка** категорий (Маникюр/Педикюр/Ресницы/Брови) — клик фильтрует прайс и прокручивает к нему.
- **Анимации**: бегущая строка-маркиза, shimmer золотого заголовка, пульс-точка «открыто», scroll-reveal секций, плавное появление карточек, магнитный hover-подсвет, счётчики статистики, пульс рейтинга.
- **Градиенты** на кнопках записи, чипсах, «Показать ещё», «Обновить отзывы».
- **Шрифты**: Cormorant Garamond (заголовки) + Onest (текст/кнопки).
- **Адаптив**: 1 → 2 → 3 колонки; на широком экране нижний dock скрывается (работает верхняя навигация). `prefers-reduced-motion` отключает анимации.

## Отличия от Mini App-версии (`../probyuti-miniapp`)

- Нет Telegram SDK и Telegram-специфики (хаптика, mainButton)
- SEO: title/description/keywords, canonical, Open Graph для превью в соцсетях
- Микроданные **schema.org BeautySalon** (JSON-LD) — карточка салона в поиске Google
- `favicon.svg` (логотипная «П» на винном фоне) и `robots.txt`
- Десктоп-адаптация: сетки в 2–3 колонки на широких экранах

## 🖥️ Сервер + база (Express + JSON-БД)

```bash
cd probyuti-site
npm install
npm start   # http://localhost:3000
```

- Данные — в `db/data.json` (создаётся из `db/seed.json` при первом старте); фото с устройства — в `db/uploads/`.
- Вход админа — `POST /api/admin/login` (bcrypt-хеш, токен на 12 ч в `sessionStorage`). Пароль задаётся через env `ADMIN_PASSWORD`, в коде и в интерфейсе не показывается.
- `db/`, `node_modules/`, `server.js` закрыты от раздачи (404).
- Без сервера сайт тоже работает — fallback на `localStorage` + сиды.

## 🖼️ Галерея работ

Вкладка **«Галерея»** с фильтром по категориям (Маникюр / Педикюр / Ресницы / Брови — без «Прочее»). Фото можно открыть в полноэкранном лайтбоксе (нативный `<dialog>`, стрелки ←/→, Esc). Пока на сервере нет фото — показываются реальные фото из отзывов Dikidi (сиды).

## 🔒 Кабинет администратора

Кнопка **🔒 Админ** в футере (вкладка «Контакты»). Вход — серверный, пять разделов:

- **🖼️ Фото** — загрузка фото для каждой категории: по ссылке (URL) или с устройства (файл сохраняется на сервер в `db/uploads/`).
- **✂️ Услуги & цены** — добавление услуг, редактирование названия/категории/цены/**скидки**/длительности, удаление. Сохраняется автоматически (дебаунс 400 мс).
- **🏷️ Скидки** — поле «Скидка %» (0–90) у каждой услуги. На главном экране: старая цена зачёркнута и уменьшена, рядом — новая цена обычным размером + бейдж `−N%`. Работает и для диапазона «от…до».
- **🔄 Синхронизация цен с Dikidi** — серверный парсинг актуального прайса (`POST /api/admin/parse-dikidi` через JSON-LD + fallback), список расхождений с чекбоксами и точечное применение.
- **🕐 Часы** — график работы (будни/выходные), отображается в блоке «Контакты».
- **⚙️ Настройки** — телефон (показ + звонок), адрес, ссылка на онлайн-запись; смена пароля (старый + новый); сброс к заводским настройкам.

## Локальный запуск

```bash
cd probyuti-site
npm install   # один раз
npm start     # http://localhost:3000 — сайт + API + админка
```

Без сервера (только вёрстка, данные из localStorage): `python -m http.server 8000`.

## Публикация

Нужен Node-хостинг (сервер + API): Timeweb Cloud, Reg.ru VPS, Railway, Render, Fly.io и т.п. Статический хостинг (Netlify/GitHub Pages) подойдёт только для витрины без серверной админки. После выбора домена замените `https://probyuti.ru/` в `index.html` (canonical, og) и `robots.txt` на реальный адрес.

## Правка контента

- **Цены/услуги**: массив `SERVICES` в `app.js`
- **Контакты/тексты**: `index.html`
- **Цвета**: переменные `:root` в `styles.css`
- **Отзывы**: обновляются автоматически с Dikidi; встроенный фолбэк — `reviews-data.js`
