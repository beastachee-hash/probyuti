# 🚀 Деплой ПроБьюти на Layero (бесплатно, через Яндекс.Диск)

Пошаговая инструкция «с нуля до рабочего сайта». Проект **многорежимный**: локально работает без облака, а в облаке с одним токеном **Яндекс.Диска** — данные и фото уходят на Диск (бесплатно, 5–10 ГБ, серверы в РФ).

**Что получится:** сайт открывается по адресу `https://…layero.app`, админка работает, фото/цены/скидки/часы общие для всех устройств и не теряются при перезапуске.

> ✅ Рекомендуемый (и бесплатный) путь — **Яндекс.Диск**. Платный облачный вариант (PostgreSQL + Object Storage) оставлен ниже как альтернатива.

---

## Шаг 0. Подготовка кода (уже в репозитории)

- `package.json`: `express`, `bcryptjs` — единственные жёсткие зависимости. Сервер слушает `process.env.PORT`.
- `.gitignore` исключает `db/data.json`, `db/uploads/*`, `.env` — в облаке они не нужны.
- `.env.example` — шаблон переменных (см. ниже).

> ⚠️ `db/` и `node_modules/` в git **не попадают**. В облаке всё живёт на Яндекс.Диске.

---

## Шаг 1. Токен Яндекс.Диска (1 минута)

1. Открой **https://yandex.ru/dev/disk/poligon/** (Полигон REST API Диска).
2. Нажми **«Получить OAuth-токен»** → скопируй токен (длинная строка `y0_AgAAA...`).
3. Сохрани его — пригодится на Шаге 4.

> 💡 При первом сохранении сервер сам создаст папку `probyuti` на твоём Диске и положит туда `state.json` (данные) и `gallery/` (фото). Ничего вручную создавать не нужно.
>
> Токен с правом только `app://` пишет в отдельную служебную папку Диска (не мусорит в личных файлах) — тогда задай `YDISK_ROOT=app://probyuti`.

---

## Шаг 2. Переменные окружения

| Переменная | Значение |
|---|---|
| `YDISK_TOKEN` | токен из Шага 1 |
| `YDISK_ROOT` | `disk:/probyuti` (или `app://probyuti` для токена приложения) |
| `ADMIN_PASSWORD` | **надёжный пароль** входа в админку (смени дефолтный!) |
| `PORT` | задаёт Layero сам — вручную не нужно |

---

## Шаг 3. Репозиторий на GitHub

1. Если ещё не под git — инициализируй и запушь (см. «Если git не установлен» ниже):
```bash
cd G:\Cline\probyuti-site
git init
git add -A
git commit -m "deploy: Yandex Disk storage"
git push
```
2. Убедись, что `.env` **не** в репозитории (он в `.gitignore`). Секреты живут только в переменных Layero.

---

## Шаг 4. Создание приложения в Layero

1. Зарегистрируйся на **layero.ru** → панель.
2. **Создать проект** → подключи **GitHub-репозиторий** `probyuti-site`.
3. Layero определит `Node.js` по `package.json`. Проверь настройки сборки:
   - **Команда запуска:** `npm start`
   - **Версия Node:** 20 (`engines.node: 20.x`)
   - **Порт:** из `PORT` — вручную **не задавай**.
4. **Переменные окружения** → добавь `YDISK_TOKEN`, `YDISK_ROOT`, `ADMIN_PASSWORD` из Шага 2.
5. **Deploy** → дождись сборки (`npm install` + `npm start`).

---

## Шаг 5. Первый запуск и проверка

1. Открой адрес `https://…layero.app` — должна открыться главная ПроБьюти.
2. В **логах** (панель Layero) должно быть:
   ```
   [storage] данные → Яндекс.Диск (disk:/probyuti/state.json)
   [storage] фото   → Яндекс.Диск (disk:/probyuti/gallery)
   ```
   Если видишь `…/db/data.json` — значит `YDISK_TOKEN` не подхватился, проверь переменную.
3. **Админка:** внизу страницы (Контакты) → кнопка **🔒 Админ** → вход паролем из `ADMIN_PASSWORD`.
4. Проверь всё:
   - Измени цену/скидку → сохрани → открой с **другого устройства** → изменения на месте (значит Диск общий).
   - Загрузи фото в галерею → обнови → картинка открывается (загрузка на Диск работает).

---

## Шаг 6. Свой домен (по желанию)

- Layero: настройки проекта → **Домены** → добавь `probyuti.ru` → пропиши у регистратора **CNAME/A-запись**, которую покажет Layero.
- После привязки обнови `og:url`/`canonical` в `index.html`.

---

## 🔄 Обновление сайта

Любой `git push` в подключённую ветку → Layero пересоберёт и перезапустит приложение. Данные и фото **не теряются** — они на Яндекс.Диске, а не в файлах контейнера.

---

## ⚠️ Важные моменты

| Момент | Что делать |
|---|---|
| **Смени `ADMIN_PASSWORD`** | дефолтный пароль знает любой, у кого есть код |
| **Токен Диска — секрет** | храни только в переменных Layero, не коммить `.env` |
| **Папка на Диске** | создаётся автоматически; при ошибке «нет папки» проверь права токена |
| **Секреты только в Layero** | `.env` в `.gitignore`, в репозиторий не попадает |

---

## 🅰️ Альтернатива: платное облако (PostgreSQL + Object Storage)

Если захочешь «как у больших» — задай в Layero:
`DATABASE_URL`, `YOS_ACCESS_KEY`, `YOS_SECRET_KEY`, `YOS_BUCKET`, `YOS_REGION`.
Код сам переключится на них (приоритет ниже, чем Яндекс.Диск). Это платно и требует настройки Yandex Cloud — для старта не нужно.

---

## ❓ Если git не установлен

В этой системе `git` ещё не установлен. Варианты:
- **Установить:** скачай с **https://git-scm.com/download/win** (Git for Windows) → при установи отметь «Add to PATH» → перезапусти терминал.
- **Или через GitHub Desktop:** **https://desktop.github.com** — GUI, без консоли.
