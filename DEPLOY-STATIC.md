# Развёртывание на хостинге Beget (без сервера, без облака)

Твой тариф не поддерживает облако — и **не нужно**. Сайт умеет работать как
**обычный статичный сайт** (как обычный `.html`). При отсутствии сервера фронт
сам переключается в режим хранения данных `localStorage` (в браузере).

## Что загрузить
Архив **`probyuti-site.zip`** (10 файлов сайта). Никаких `server.js`, `storage.js`,
`package.json`, `node_modules` — они не нужны для статичного режима.

## Шаги в панели Beget

1. **Сайты** → создай (или открой) сайт, прикрепи к нему домен.
2. Открой **Sprut.io** (файловый менеджер) и зайди в папку сайта
   (обычно `.../probyuti.ru/public_html` — именно туда, где лежит сайт).
3. **Загрузи** туда файл `probyuti-site.zip`.
4. Нажми на нём правой кнопкой → **Распаковать / Извлечь сюда**.
5. Убедись, что `index.html` лежит **прямо** в `public_html` (не во вложенной папке).
6. Открой домен в браузере — сайт работает.

## Обновление сайта позже
Просто залей новые файлы через Sprut.io (перезапись), архив/файлы не привязаны к серверу.

---

## ⚠️ Важный нюанс про «Кабинет администратора» в статичном режиме

В этом режиме **нет общего сервера**. Изменения, которые ты вносишь в админке
(фото в галерее, цены, телефон, адрес, часы), сохраняются **только в твоём браузере**
(`localStorage`). Это значит:

- **Ты** видишь свои правки — да (на том устройстве/браузере, где вносил).
- **Посетители** сайта эти правки **не увидят** — у них останутся «заводские»
  данные из кода (`app.js` / `store.js`), пока ты вручную не поправишь их в файлах.
- Мобильная связь / любой интернет: **сайт откроется** (проблема «не работает с телефона» решена),
  но общий контент — только тот, что зашит в код.

### Когда понадобится сервер
Если захочешь, чтобы **все посетители** видели твои изменения из админки в реальном
времени (общая база) — тогда нужен серверный режим (VPS/облако). Для статичного
режима правки цен/фото делай прямо в файлах `app.js` (цены) и `store.js`/`gallery.js`
(фото) и загружай обновлённые файлы на хостинг.
